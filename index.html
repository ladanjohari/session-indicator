Session Indicator — a native macOS menu bar component for AI agent supervision

When multiple AI agents run in parallel, developers lose awareness. The Session Indicator restores it — without interrupting focus.

Five states. No learning curve.

Idle
No active agent. Dot stays dim and quiet.
Active
Shimmer · actively executing right now
Waiting
Amber · alive but not progressing
Error
Needs attention. Red, static, no animation.
Done
Green · stays visible until you close the popover — closing is your acknowledgment.

How it was designed

Borrowed, not invented

Same visual grammar as Ethernet LEDs and the macOS camera indicator. Zero new concepts to learn.

Motion = state. Color = exception.

White dots handle 90% of cases. Color only fires for error and completion.

Hardware and software share one language.

The same dot pill lives in the SD card slot when the lid is closed.

Eight indicator variations — try them live with keys 1–8

Each dot above is live. Press 1–8 on your keyboard to switch the prototype.

Minimal

no motion, white only

Active — solid white
Waiting — dim white, no motion
+Zero distraction. Works with Reduce Motion on.
+No color language at all — purely ambient.
–Active looks identical to idle at a glance.
–No color means waiting has no urgency signal.

Pulse

pulse speed as the only signal

Active — fast pulse
Waiting — slow pulse
+Speed communicates urgency intuitively.
+Feels alive and responsive.
–Two speeds can be subtle — easy to miss at a glance.
–Fast pulse can be distracting in peripheral vision all day.

Speed is the only signal — no color difference

Semantic

motion + color each carry one meaning

Recommended
Active — shimmer
Waiting — amber, static
+Color carries meaning: amber = held up, white = running. Two distinct signals.
+Shimmer is subtle enough for all-day peripheral use.
–Requires learning the color language once.
–Motion and color are two simultaneous signals.

Our recommendation: Semantic (Pulse, key 1). The core insight is that these variations change the color language, not just motion. Semantic is recommended because color carries meaning — amber for blocked, white for running. Keeping motion and color as separate channels means each signal stays clean and readable at a glance.

Six additional variations — Pixel Heart (2), Pixel Art (3), Pixel Flame (4), Waveform (5), Agent Meter (6), Orbital (7), and Claude Native (8) — are available in the prototype via keys 2–8.
