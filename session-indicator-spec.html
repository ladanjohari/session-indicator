Session Indicator — Design Spec v0.1 — Working Document

01 · Dot state vocabulary

Each dot in the pill represents exactly one agent session. Dots are fully independent — each responds only to its own session state.

Idle

connected, no task

Dim, no motion. The session is open and linked but has nothing running. Recedes without disappearing.

Active

running right now

Solid white, no motion. Bright and present — like a lit LED. Stillness signals confidence, not inactivity.

Waiting

paused or queued

White, slow pulse. Alive but not progressing. The breathing rhythm signals patience, not urgency.

Error

needs attention

Red, static. Color alone is the signal — no motion. Motion on an error creates panic. Static red is the universal hardware fault indicator.

Done

task completed

Green, holds 3 seconds then fades out — the dot shrinks and disappears. Hovering the pill pauses the fade. The session closing is itself the confirmation.

Green fade — timing rationale

3 seconds: long enough to register at peripheral vision, short enough not to linger. Auto-fade keeps the pill self-managing. Hover-to-pause gives users a way to inspect if they missed it. Exact duration is a candidate for user research and a possible preference setting.

02 · Mixed state — real-world pill

Four sessions open simultaneously. Each dot is independent — no synchronised motion.

03 · Design principles

Motion = state. Color = exception.

For 90% of usage the pill shows white dots with varying motion states. Color only fires for error (red) and done (green briefly). This keeps the indicator calm and reserves color for moments that genuinely need attention.

No amber

Amber universally reads as caution in LED language. White shimmer communicates active work without the anxiety amber introduces.

Reduce Motion

When macOS Accessibility > Reduce Motion is enabled: all dots render as static colored dots. No animation at all.

Per-dot only

The pill never animates as a unit. Each dot follows only its own session. No synchronised motion across the group.

04 · Name

Sessions

Honest and OS-native. Already used in Xcode and Terminal. Zero learning curve. Slightly generic.

Flow

Short and human. Describes the state of work without technical baggage. Risks being too abstract.

selected

Session Indicator

Follows Apple HIG naming exactly — noun plus Indicator. Already in their vocabulary. Precise, descriptive, zero ambiguity.
