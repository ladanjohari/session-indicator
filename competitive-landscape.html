Competitive Landscape

Every existing tool that touches AI agent monitoring on macOS — what each one does, where each one stops.

Live session monitors
closest to what we are building

c9watch

github.com/minchenlee/c9watch

Tauri · Rust · Svelte · MIT · open source

Auto-discovers every running Claude Code session by scanning OS-level processes. No plugins needed, works with any terminal or IDE. Shows Working, Need Attention, or Idle per session in a dashboard. Reads JSONL files for deep content and session search. Built by one developer who was running 10+ sessions across Zed and Ghostty. Also has a YouTube demo.

auto-discovery no plugins needed Tauri, minimal footprint session search no dot pill design no hardware surface list UI, not ambient

CC Status Bar

github.com/usedhonda/cc-status-bar

Swift · native macOS · open source · Jan 2026

The most feature-complete in this category. Red and yellow alerts when sessions need attention. One-click focus jumps to the exact terminal window or IDE tab. Autofocus mode brings the right window to front automatically when Claude needs input. Works with both Claude Code and Codex CLI. iPhone companion app via vibeterm. Cmd+Shift+C shortcut for quick session focus. Color theme customization.

one-click terminal focus autofocus mode iPhone companion Claude Code + Codex color and label UI, no dot pill no ambient design no hardware surface

claude-status

github.com/gmr/claude-status

Swift · Claude Code plugin · Mar 2026

Uses a bundled Claude Code plugin that hooks into session lifecycle events. The plugin writes .cstatus files and posts Darwin notifications for instant state updates — real-time push, not polling. Also includes a macOS Desktop Widget. Supports VS Code, Zed, Xcode, JetBrains, iTerm2, Warp, Ghostty, tmux and more. Includes productivity scoring.

plugin hook architecture real-time push desktop widget broadest IDE support no dot pill design no hardware surface
Quota monitors
solving a different problem

ClaudeBar

github.com/tddworks/ClaudeBar

Swift 6.2 · native macOS · open source · active May 2026

Monitors usage quotas across 9 providers simultaneously: Claude, Codex, Gemini, GitHub Copilot, Amp, Kiro and more. Color-coded progress bars, system notifications when limits approach. Multiple themes. Native Swift, system appearance adaptive.

9 providers native Swift multiple themes quota only, no session states no per-session live status

ClaudeWatch

github.com/elliotykim/claudewatch

Swift · open source · Apr 2026

Tracks 5-hour session windows with a 26-week usage heatmap, session streaks, burn rate, and peak usage stats. Popover with calendar view showing daily session counts. Writes usage data via a shell statusline hook. Focused on quota analytics over time, not live session state.

26-week usage heatmap session streaks no live session monitoring analytics only

claude-monitor

github.com/rjwalters/claude-monitor

Open source · API-based · updated May 2026

Reads usage from API response headers with a single curl call. Multi-account support with pinning, sorting, and per-account charts. The entire app wraps one API call. Extremely lightweight and transparent about what it does.

multi-account minimal footprint fully transparent no session states quota only
Terminal statusline plugins
inside the terminal, not the menu bar

Claude HUD

github.com/jarrodwatts/claude-hud

Claude Code plugin · 18k GitHub stars · Apr 2026

The most popular in this space by far. Shows context usage, active tools, running subagents, and todo progress directly in the terminal statusline. Displays detail like “explore [haiku]: Finding auth code (2m 15s)”. Highly configurable element order, colors, and git status integration. Described by reviewers as “the status bar Claude Code should have built in.”

18k stars subagent tracking todo progress most popular in category terminal only, not OS-level no ambient menu bar presence

claude-code-usage-bar

github.com/leeguooooo/claude-code-usage-bar

Python · Claude Code statusline plugin · Apr 2026

Lightweight terminal statusline showing 5h/7d rate limits, reset countdowns, model name, context window percentage, and prompt-cache age — all in one compact line. Three display styles and nine themes. Daemon fast-mode keeps CPU usage under 1% continuously. Install with one pip command.

9 themes very lightweight one-line install statusline only no menu bar presence

The three worth installing before you build

c9watch, CC Status Bar, and Claude HUD. Between those three you will feel exactly what exists, what works well, and what the dot pill design does that none of them do. The gap is real and it is unoccupied.
